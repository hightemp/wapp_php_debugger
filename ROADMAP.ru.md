# Дорожная карта

[English](ROADMAP.md) · **Русский**

Что есть в 1.0 и что будет после неё. Подробный рабочий план —
[IMPROVEMENT_PLAN.ru.md](IMPROVEMENT_PLAN.ru.md); идеи и баги — в issues.

## 1.0

- **Просмотрщик** (`wapp-debugger serve`) и **десктоп-приложение** (Linux, macOS, Windows) на одном ядре:
  проекты на этой машине, по SSH, через HTTP-режим библиотеки или с отправкой логов в просмотрщик;
  много серверов со своими окружениями.
- **PHP-библиотека 2.x** для PHP 7.4+, без зависимостей: ошибки, исключения, SQL- и HTTP-запросы,
  таймеры, маскировка секретов; PSR-3, Monolog, Guzzle; Laravel, Symfony, WordPress и 1С-Битрикс
  ([интеграции](client-php/integrations/README.ru.md)); JS-клиент для ошибок страниц; агент для
  хостов без SSH.
- **UI**: шкала времени, SQL с N+1, суперглобальные массивы, исходник вокруг строки, фильтры,
  командная палитра, сравнение запросов, экспорт и импорт, свои темы.
- **Контракты заморожены** ([spec/frozen](spec/frozen/README.ru.md)): формат логов v2 и API v1 в
  течение 1.x меняются только обратно совместимо.

## Дальше

**Просмотрщик**

- Панели, которые меняют размер и сворачиваются; серверы в дереве проектов; узкая раскладка.
- Страница настроек проекта с маппингом путей (сервер или контейнер ↔ локальная копия) и его проверкой.
- Строка состояния: live-поток, каждый сервер, ещё не импортированные файлы, место на диске.
- Онбординг для пустого просмотрщика; вкладка сырого JSON у сообщения; вкладки обзора и ошибок у
  запроса; сохранённые фильтры и диапазон дат.

**Источники**

- Live tail по SSH (`inotifywait`/`tail -F` на сервере) вместо опроса; сжатие и лимит скорости на
  сервер.
- Квоты ретеншна на сервер; конфиг-файл серверов и проектов для правки вручную.
- Пароли ключей и SSH-пароли в системной связке ключей.

**Десктоп**

- Десктоп-приложение, открытое и для браузера (локальный порт с токеном).
- Заголовок окна в цветах темы, запоминание раскладки панелей, логи, брошенные на окно.
- Подписанные и нотаризованные сборки (Developer ID, Authenticode).

**Библиотека**

- Packagist (split `client-php/` в собственный репозиторий).
- Пакеты для фреймворков (Laravel service provider с автообнаружением, Symfony bundle), если будет
  спрос: сегодня то же самое покрывают файлы интеграций.
