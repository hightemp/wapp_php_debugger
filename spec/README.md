# spec

Общие контракты для PHP-библиотеки (`client-php/`), Go-сервера (`server/`) и UI (`ui/`).

| Путь | Что | Фаза |
|---|---|---|
| `fixtures/v1/` | Реальные логи текущего формата v1 и `manifest.json` с их эталонными свойствами | 2 ✅ |
| `logformat/` | JSON Schema форматов v1 и v2 | 3 |
| `openapi.yaml` | API просмотрщика v1 (включая HTTP-режим библиотеки) | 3 |
